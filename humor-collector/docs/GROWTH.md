# 많이 보이게 하려고 넣은 규칙과 그 근거

대본 단계(`plot`, `script`)에는 인스타그램에서 더 많은 사람에게 보이게 하려는 규칙이 들어 있습니다.
이 문서는 규칙마다 근거가 무엇이고 얼마나 믿을 만한지 적습니다. 확인한 날은 2026-11-10입니다.
주장 하나하나의 출처 링크는 [GROWTH_SOURCES.md](GROWTH_SOURCES.md)에 있습니다.

## 먼저 알아 둘 것

- **도달을 보장하는 규칙은 없습니다.** 인스타그램은 어떤 행동을 예측하는지는 공개하지만 가중치 숫자는 공개하지 않습니다.
- 근거는 네 종류로 나눠 적었습니다. 뒤로 갈수록 약합니다.

| 표시 | 뜻 |
|---|---|
| 공식 | 메타·인스타그램·OpenAI의 공식 문서 |
| 발언 | 인스타그램 대표(아담 모세리)나 공식 계정의 말. 대부분 언론 보도를 거쳐 확인했습니다 |
| 통계·관행 | 업체가 낸 통계, 작가 인터뷰, 업계 관행. 원인과 결과를 보여 주지는 않습니다 |
| 추론 | 위 자료에서 이 프로그램이 끌어낸 값. 글자 수, 여백, 픽셀 크기가 여기에 듭니다 |

- 업체 통계(참여율 몇 %, 도달 몇 배)는 프로그램의 기준값으로 쓰지 않았습니다. 업체마다 결론이 다릅니다.
- 조사는 AI 조사 에이전트가 했고, 주제마다 두 번째 에이전트가 핵심 주장의 출처를 다시 열어 봤습니다.
  사람이 원문을 모두 읽고 검수한 것은 아닙니다. 중요한 결정에 쓰기 전에는 링크를 직접 열어 보세요.

## 1. 인스타그램이 공개한 것

| 내용 | 근거 |
|---|---|

| 탐색 탭은 좋아요, 저장, 재공유, 댓글, 팔로우, 5초 넘게 보기, '관심 없음'을 예측한다 | 공식 (탐색 시스템 카드, 2026-06 갱신) |

| 해시태그는 게시물당 5개까지다. 해시태그는 도달을 늘리는 수단이 아니다 | 발언·보도 (2025-12) |

## 3. 올릴 때 사람이 정할 것

- **원문과 나란히 놓고 보기.** 자동 검사는 문장 베끼기만 잡습니다. 사건의 세부 순서가 원문과 똑같으면 세부를 바꾸세요.
- **피드에는 직접 만든 만화만.** 남의 게시물을 소개하려면 다시 올리지 말고 스토리 공유나 리포스트 기능을 쓰세요.
  추천에서 빠진 계정은 최근 게시물의 상당 비율이 원본으로 판정되어야 회복된다고 합니다(공식).
- **음악(선택).** 캐러셀에 음악을 넣으면 릴스 탭에도 노출될 자격이 생긴다고 합니다(모세리 2024-10 발언).
  얼마나 더 노출되는지는 공개된 숫자가 없습니다.
- **올리는 횟수.** 한국 인스타툰 작가들은 주 2~3회가 흔합니다(관행). 그 횟수가 성장을 만든다는 비교 자료는 없습니다.
- **3:4로 올리는 방법.** 앱에서 직접 올리면 3:4를 쓸 수 있습니다. API로 올리는 도구는 4:5까지만 받을 수 있습니다(공식 API 규격).
  쓰는 도구가 3:4를 받지 않으면 `[studio.format] canvas`를 `1080x1350`으로 바꾸세요.
- **계정 상태 확인.** 프로페셔널 계정의 '계정 상태'에서 추천 대상인지 가끔 확인하세요.

## 4. AI로 만든 그림과 글의 표시

| 내용 | 근거 |
|---|---|
| 메타가 게시자에게 AI 라벨을 요구하는 대상은 사실적인 영상과 사실처럼 들리는 음성이다. 이미지는 필수 대상이 아니고, 만화풍은 라벨이 필요 없는 예로 나온다 | 공식 (메타 도움말, 2026-10 갱신) |
| 게시자가 표시하지 않아도 메타가 파일에 든 신호를 읽어 AI 라벨을 자동으로 붙일 수 있다 | 공식 |
| 'AI 생성 프로필' 라벨은 AI로 만든 "사람"을 내세우는 계정이 대상이다. 만화 캐릭터 계정이 대상인지는 문서에 없다 | 공식, 일부 미확인 |
| 한국 인공지능기본법(2026-01-22 시행)의 표시 의무는 AI 사업자에게 있다. AI로 만화를 만들어 올리는 개인 창작자는 의무 주체가 아니다 | 법령, 보도 |
| 게시자에게 표시 의무를 지우는 정보통신망법 개정안이 국회에 올라와 있다. 통과되지는 않았다 | 국회 의안 정보 (2026-11-10 열람) |
| AI가 만든 그림은 저작물로 보지 않는다. 글은 사람이 쓰고 그림은 AI가 만들면 글 부분만 등록된다 | 한국저작권위원회 안내 (2025-06) |
| AI 결과물이 남의 저작물을 침해하면 책임은 보통 지시문을 입력한 사람이 진다 | 해설 기사 (2025-07) |

그래서 이 프로그램은 이렇게 합니다.

- 제작 방식 표시 문구는 설정(`[studio.production] disclosure`)으로 둡니다. 지금은 법적 의무가 아니고, 붙일지는 운영자가 정합니다.
  표시가 도달에 주는 영향은 확인된 자료가 없습니다. 게시자 표시 의무 법안이 통과되면 반드시 켜세요.
- 그림 도구가 넣은 AI 표시와 메타데이터를 지우는 단계는 만들지 않았습니다.
- 그림 지시문에는 특정 작가·작품·기존 캐릭터를 닮게 하라는 말을 넣지 않습니다.
- LLM이 쓴 대본을 사람이 고르고 고친 기록을 남겨 두세요. 사람이 기여한 부분만 보호받을 수 있습니다.

## 5. 커뮤니티 글을 각색할 때의 저작권

이 부분은 법률 자문이 아닙니다. 찾은 판결과 안내를 정리한 것입니다. **커뮤니티 글을 각색한 만화나 영상을 직접 판단한
한국 판결은 찾지 못했습니다.**

| 내용 | 근거 |
|---|---|
| 저작권은 표현을 보호한다. 아이디어와 사실 자체는 보호하지 않는다. 전형적인 사건·배경·인물 유형은 아이디어 쪽이다 | 대법원 99다10813, 2014다14375, 2004도5350 |
| 원작과 실질적으로 비슷한 채로 고치면 2차적저작물이고, 실질적으로 비슷하지 않으면 새 저작물이다 | 저작권법 제5조·제22조, 대법원 2007다63409 |
| 원글을 보고 만들었는지(의거)와 실질적으로 비슷한지는 따로 판단한다 | 대법원 2013다8984. 이 프로그램은 원글을 보고 만들므로 남는 쟁점은 비슷한지뿐이라는 것은 이 문서의 추론입니다 |
| 남의 SNS 글 수십 개를 이름 없이 고쳐 자기 글처럼 올린 사람이 저작권법 위반으로 유죄가 확정됐다. SNS 글도 저작물로 다뤄졌다 | 대법원 2020도10180 (2023-11-30) |
| 출처를 적는 것은 허락을 대신하지 않는다 | 문화체육관광부 안내, 저작권법 제37조 |
| "몇 글자, 몇 초까지는 괜찮다"는 기준은 법령과 판결 어디에도 없다. 법원이 보는 것은 길이가 아니라 창작성이다 | 저작권법 제28조·제35조의5 |
| 제목은 저작물로 보호받지 못한다. 짧고 흔한 문구도 보호받기 어렵다. 다만 짧은 글의 저작물성을 인정한 사례도 있고, 유행어가 상표로 등록돼 있을 수 있다 | 대법원 96다273, 서울중앙지법 2012카합996 |
| 인기 영화·드라마의 장면이나 포스터를 바꿔 쓰는 것만으로는 허용되는 패러디가 아니다 | 문화체육관광부 정책브리핑 (2024-03-06) |
| 이름을 쓰지 않아도 주위 사정으로 누구인지 알 수 있으면 당사자가 특정된다. 가명을 써도 주변 사람이 알아보면 사생활 침해가 된다 | 대법원 2000다50213, 96다11327 |
| 유명인의 이름·초상·음성·서명 같은 표지를 자기 영업에 무단으로 쓰면 부정경쟁행위다. 유행어가 여기에 드는지 판단한 판결은 없다 | 부정경쟁방지법 제2조 제1호 타목 (2022-06-08 시행) |
| 2026년 개정으로 저작재산권 침해의 처벌 상한이 7년 이하 징역 또는 1억 원 이하 벌금이 됐고, 고의 침해에는 손해액의 5배까지 배상하게 됐다 | 저작권법(법률 제21336호, 2026-02-10 공포). 시행일은 해설 자료로만 확인했습니다 |
| 표현을 바꾼 각색은 '소재 차용'으로 분류돼 규제가 닿지 않는다고 교수 한 사람이 말했다. 허용된다는 뜻이 아니라 공백을 지적한 말이고, 대상은 유튜브 쇼츠다 | 보도 (경향신문 2026-08-02) |

그래서 이 프로그램은 이렇게 합니다.

- 지시문은 웃음의 구조만 가져오고 장소·소품·숫자·고유명사·문장을 모두 바꾸라고 합니다. 프로그램은 원문과 연속으로 같은 글자(12자)와
  닮은 문장(85점)을 검사합니다. **이 숫자는 운영 기준이지 법적 기준이 아닙니다.**
- 실명, 계정 이름, 가게·회사·상표를 넣지 말라고 하고, 링크·계정 이름·이메일·전화번호처럼 보이는 것은 오류로 막습니다.
  누군가의 병·범죄·빚 같은 민감한 사생활이 중심인 글과 뉴스에 나와 당사자가 드러나는 사건은 쓰지 말라고 합니다.
  평범한 가족·직장 일화는 누구인지 알 단서를 지우면 쓸 수 있습니다.
- 각색한 이야기를 실화라고 소개하면 '확인'으로 알립니다. 법이 요구하는 것은 아니고, 정직한 표시를 위한 운영 기준입니다.
- 한 글에서는 한 편만 만듭니다(플롯이 있는 글은 후보 목록에서 빠집니다).
- 참고한 글의 주소는 대본의 '내부 기록'에만 남깁니다. 게시물에는 붙이지 않습니다. 출처 표시는 허락을 대신하지 않고,
  링크는 당사자를 드러낼 수 있습니다.
- 원글 작성자가 내려 달라고 하면 `forget` 명령으로 수집한 글을 지웁니다. 올린 만화는 사람이 직접 내려야 합니다.
  내린다고 책임이 사라지는 것은 아닙니다.
- 고전 개그는 대사 한 줄이나 포즈처럼 작게만 쓰고, 원본 장면·인물·로고를 따라 그리라는 지시를 만들지 않습니다.
  한 편에 최대 1개라는 한도는 운영 기준이지 법적 안전선이 아닙니다.
- **광고·협찬 편에는 유명인의 이름·얼굴·목소리를 쓰지 않습니다. 유행어와 밈도 빼는 것을 원칙으로 하세요.**
  `plot write --no-classics`로 만들면 고전 개그 없이 씁니다.

하지 않은 것도 있습니다.

- 원문을 LLM에 보여 줍니다. 원문을 보여 주지 않고 '상황 요약'만 넘기는 더 보수적인 2단계 방식은 넣지 않았습니다.
- 사건의 순서가 원문과 같은지는 검사하지 못합니다. 짧은 농담은 구조가 곧 내용이라, 바꿔 써도 같은 농담으로 읽힐 수 있습니다
  ([샘플 2번](samples/README.md)이 그런 예입니다). 사람이 보고 판단해야 합니다.
- 원문이 영어 글이면 번역해 옮긴 문장을 잡지 못합니다. 이때는 '확인'으로 알립니다.
- 커뮤니티마다 다른 약관(게시물의 저작권이 누구에게 있는지)은 확인하지 못했습니다.

## 6. 그림 생성 도구(ChatGPT)에 대해 확인한 것

`script prompts`가 만드는 지시문의 문구는 아래 내용에 맞췄습니다.

| 내용 | 근거 |
|---|---|
| ChatGPT의 그림 기능은 GPT Image 계열 모델이다. 2026-11-04에 GPT-Image-2.6이 나왔고, DALL·E는 2026-05-12에 API에서 제거됐다 | 공식 (OpenAI 개발자 변경 기록) |
| 화면비는 3:1에서 1:3 사이를 지원한다. 3:4는 그 안에 있다 | 보도 (2026-04, Images 2.0 출시 기사 여러 건). 현재 버전에서도 같은지는 따로 확인하지 못했습니다 |
| 화면비, 구도, 중요한 배치 조건은 지시문에 직접 적으라고 한다 | 공식 (이미지 프롬프트 가이드) |
| ChatGPT에서는 픽셀 크기를 정할 수 없고, 요청한 비율도 근사값으로 나온다 | OpenAI 포럼의 사용자 보고 (2026-10). API 규칙으로도 가로·세로가 16의 배수여야 해서 1080×1440은 바로 만들 수 없습니다(공식) |
| 넣을 글자는 따옴표로 감싸고, 위치와 글꼴을 적고, 몇 번 나오는지 적고, 그 밖의 글자는 넣지 말라고 적는다. 결과물의 철자를 확인한다 | 공식 (이미지 프롬프트 가이드) |
| 글자의 위치와 선명도, 여러 번 나오는 캐릭터의 일관성은 여전히 틀릴 수 있다 | 공식 (이미지 생성 가이드의 한계 항목) |
| 캐릭터를 유지하려면 기준 그림을 먼저 만들고(글자 없이, 단순한 배경), 다음 그림마다 생김새 조건을 다시 적고, 캐릭터를 다시 디자인하지 말라고 적는다 | 공식 (이미지 프롬프트 가이드) |
| 공식 문서의 만화 예시는 4컷을 한 장에 그리는 방식이다. 컷마다 따로 그리는 예시, 말풍선과 한국어에 대한 안내는 없다 | 공식 |
| 고칠 때는 앞 결과를 놓고 한 가지만 바꾸라고 하고, 그대로 둘 것을 다시 적는다 | 공식 |
| 2026-04의 Images 2.0에서 한국어를 포함한 비라틴 문자 표기가 크게 나아졌다고 발표했다 | 보도. 한글 정확도 숫자는 공식 자료에 없습니다 |
| 간판·포스터 크기의 짧은 한글은 잘 나오고, 작은 글씨와 빽빽한 글자는 흔들린다. 글자가 안 맞으면 빈 말풍선으로 그리고 글자를 따로 넣는다 | 실무자 글 여러 건(일부는 다른 그림 도구에 대한 글). 만화 말풍선의 한글을 따로 시험한 자료는 찾지 못했습니다 |
| 올린 참조 그림을 따르지 않거나 컷마다 얼굴이 달라진다는 보고가 있다 | OpenAI 포럼의 사용자 보고 (2026-08~10) |

그래서 지시문은 이렇게 만듭니다.

- 비율은 "세로로 긴 3:4 비율(가로 3, 세로 4)"처럼 말로 적고 픽셀 수는 요구하지 않습니다. 그림을 받은 뒤 크기를 맞춥니다.
- 글자는 따옴표 안에 그대로 적고 "각각 한 번씩", "그 밖의 글자는 넣지 않는다"를 붙입니다.
- 캐릭터 생김새와 그림 방향을 컷마다 같은 문장으로 반복하고, 캐릭터 시트(글자 없음)를 먼저 만들게 합니다.
- 컷 지시문에는 "4컷 만화"나 "몇 번째 컷"이라는 말을 쓰지 않습니다. 공식 예시가 4컷을 한 장에 그리는 방식이라,
  그런 말이 있으면 한 장에 칸을 나눠 그릴 수 있기 때문입니다(추론).
- 대본 단계에서 한 컷의 글자를 4덩어리 이하, 그림 속 글자를 1개·14자 이하로 권합니다. 측정된 한도가 아니라 예방 조치입니다.
- 글자 없는 그림용 지시문(`--no-text`)도 함께 만듭니다.

**이 지시문으로 실제 그림을 만들어 보지는 못했습니다.** 이 프로그램을 만든 환경에는 그림 생성 도구가 없습니다.
아래는 직접 해 봐야 알 수 있습니다.

- ChatGPT의 비율 선택 메뉴에 3:4가 있는지, 3:4를 요청하면 실제로 몇 픽셀로 나오는지
- 말풍선 속 한글이 얼마나 정확하게 나오는지(특히 받침이 많은 글자, 말풍선 2개인 컷)
- 같은 대화에서 이어 그리는 것과 컷마다 캐릭터 시트를 올리는 것 중 어느 쪽이 캐릭터가 덜 달라지는지
- 참조 그림을 이름으로 저장해 다시 부르는 기능(2026-11 보도)이 만화 캐릭터에도 잘 듣는지
- 지시문을 영어로 쓰고 대사만 한국어로 두면 더 나은지(근거를 찾지 못했습니다)

## 7. 확인하지 못했거나 넣지 않은 것

- 숫자로 된 통념은 모두 출처를 찾지 못했습니다: "저장은 좋아요의 3배", "캐러셀은 도달 1.4배", "8~10장이 최적",
  "첫 장이 80%를 좌우", "AI 라벨이 붙으면 도달이 몇 % 준다", "참여 유도 문구는 도달을 50~90% 줄인다".
- 남의 일화를 새 글과 새 그림으로 다시 만든 만화가 인스타그램에서 원본으로 판정된다고 직접 말한 공식 문장은 없습니다.
  "직접 디자인한 콘텐츠는 원본"이라는 문구에 기댄 해석입니다. 인스타그램은 원본성 정책과 지식재산권 정책이 별개라고 밝힙니다.
- 4컷이 10장 안팎 형식보다 반응이 좋은지 비교한 자료, 만화·유머 계정만 본 형식별 자료, 한국 이용자 자료는 찾지 못했습니다.
- 개인이 운영하는 음식 캐릭터 인스타툰의 사례는 찾지 못했습니다. 확인한 음식 캐릭터 계정은 기업 계정뿐입니다.
- 인스타그램이 이미지 안의 글자를 읽어 참여 유도 문구로 판정하는지는 확인하지 못했습니다.
- 올리기 좋은 요일과 시간대는 근거를 찾지 못해 규칙으로 넣지 않았습니다.
- **올린 만화의 성과를 다시 읽어 와 다음 소재 선택에 반영하는 기능은 아직 없습니다.** 지금은 플롯마다 방향(반전형·공감형·대화형)과
  쓴 개그만 기록합니다.
